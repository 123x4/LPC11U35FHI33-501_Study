ADC：从上电到每 1 ms 读出两个数

把项目里所有和 ADC 有关的代码按执行顺序串起来，每一行都讲：它改了哪个寄存器的哪几位、手册在哪一页、为什么这么写。第 7 课讲过 ADC 的原理，这一页专讲代码；第 4 节接着讲读出来的数怎么变成“按着 / 松着”。

1/8🧭 本质

在这个项目里，ADC 只干一件事：每 1 ms，把左右两个红外接收管上的电压，各变成一个 0~1023 的数。

用 ADC 分三步，和第 3 课的“外设七步”一一对应：① 开电源、开时钟、设分频（只做一次）→ ② 把引脚切成模拟输入（每个通道一次）→ ③ 每次要数时：选通道 → 启动 → 等 DONE → 取结果。这一页的代码全部落在这三步里。

4/8读出来的数之后：按键算法（my_misc.c）

🧭 本质：把“一个电压数”变成“按着 / 松着”。难点在于每只鼠标、每对红外管、每个温度下，没按时和按到底的电压都不一样，所以不能写死一个阈值，而是让程序自己学两条基线，再看当前值落在两条线之间的哪里。

整个模块在 src/my_misc.c（本项目 chengjie 写，2026-03），入口是 ProcessRecvSampleRawData()（418 行），每 1 ms 被 LR_GetState() 调一次，左右两个键各走一遍下面这条流水线（点一格跳到说明）：

① 拼数、取反→② 开机学基线（≤ 600 ms）→③ 线圈在震就冻结→④ 滤波→⑤ 算按下程度 0~100→⑥ 快速触发：按着 / 松着→⑦ 校准两条基线→⑧ 交出结果
两条基线（取反之后，数越大 = 按得越深）：
顶部基线 gwTopBaseline = 没按时的数值；底部基线 gwBottomBaseline = 按到底时的数值。
按下程度（段位，0~100） = 当前值在两条线之间的位置：贴着顶部是 0，到底部是 100。下标 0 = 右键，1 = 左键。
动手 · 逐毫秒模拟（和 C 代码同一套算法，左键一路）
滤波后的值 temp顶部基线底部基线按下程度（右轴 0~100）判定为“按着”

手指按下的深度是我编的（没按时 ADC ≈ 800，按到底 ≈ 420，带 ±2 的噪声）；算法部分照抄 C 代码：学基线、滤波、查 nodeCaliTable、快速触发、两条基线的校准。线圈冻结没有模拟。

② 开机学顶部基线：Hall_InitBaseline()（my_misc.c:135~160，调用在 441~456）

场景：鼠标刚插上，程序还不知道“这一只鼠标、这一对红外管，没按时读数是多少”。开机后的头几百毫秒，先假设手指没按，把读数学下来当作顶部基线。学好之前，左右键都不判断，一律当松着。

138    uint16_t upperLimit = *pTopBaseline + (MAGNETIC_NOISE);  // 当前顶部基线 + 20
139    uint16_t lowerLimit = *pTopBaseline - (MAGNETIC_NOISE);  // 当前顶部基线 − 20

144      *pBottomBaseline = rawData;

行讲解
135参数：keyIndex 哪个键（0 右 / 1 左）；rawData 这一毫秒取反后的读数；后两个是指针，指向全局的 gwTopBaseline[k]、gwBottomBaseline[k]。传指针是为了让函数能直接改调用者的变量（C 函数只有一个返回值，返回值已经用来报“学好没有”，基线只能通过指针改回去）。*const 表示指针本身不能改指向，但它指的数可以改。
137static 局部数组：两个键各一个计数，函数返回后还记得。用来数“连续稳定了几毫秒”。
138~139MAGNETIC_NOISE 在 IRPT_V4 下 = 20（my_hallkey_func.h:22，名字是霍尔板型留下的，这里指 ADC 噪声）。以当前顶部基线为中心，±20 算“稳定”。
141~146新读数跳出 ±20：说明还不稳（刚上电、手指在动）。直接把基线换成这个新读数，计数清零，重新数。顶部基线初值是 10000（my_misc.c:74），这是一个 10 位 ADC 不可能出现的值，所以第一次调用一定走这里，等于“用第一个读数开局”。
148~151在 ±20 以内：把基线和新读数取平均（新读数占一半），慢慢收敛到真实值；底部基线设成和顶部一样，因为这时还不知道“按到底”是多少。
152~157连续稳定满 100 次（100 ms）就返回 0。counter = 100 这句没有实际作用（之后不会再调用这个函数）。
调用处 453~455返回 0 → cali_init_cnt = 0，学习阶段立刻结束。如果 600 ms 都没学好，cali_init_cnt 也会减到 0，用当时手上的基线凑合，代码里没有任何提示。
⚠️ 两个从代码推出来的问题（待上板验证）
1. 任何一个键学好，两个键一起结束。第 455 行在 for 循环里：右键（k = 0）先稳定满 100 ms，就把 cali_init_cnt 清 0，左键学没学好都不管了。
2. 开机时手指搭在键上，会把“按下”学成“没按”。函数只看“稳不稳”，不看“是不是没按”。手指按着不动，读数也很稳，就被当成了顶部基线。之后：两条线重合在“按下”的位置，段位一律 0，这个键按不出来；要等手指松开后，顶部基线靠 ⑦ 的校准每 300 ms 往回挪 20，挪够了才恢复。下面的模拟里，场景 3 演示问题 1（左键没学稳就被右键带着结束了），场景 2 演示问题 2：开机时左手指搭在左键上 300 ms，左键大约 3 秒后才第一次响应，再过好几秒，顶部基线才回到正常值。
可能的改法（示意）：两个键都学好才结束（用两个标志）；或者学习期间读数如果明显偏向“按下”一侧就不采用；或者把学到的基线存进 EEPROM，开机时先用上次的值。改之前先问杰哥。

④ 滤波（my_misc.c:534~545）

if(|上次滤波值 − 新值| > 10)          // FILTER_SKIP_VALUE = 10
{
  raw_data_filter[k] = temp[k];                  // 变化大：直接跟上
  raw_data_filter_sum[k] = temp[k] << 4;         // 累加和 = 新值 × 16
}
else
{
  raw_data_filter_sum[k] += temp[k];             // 加上新值
  raw_data_filter_sum[k] -= raw_data_filter[k];  // 减掉一份旧平均
  raw_data_filter[k] = raw_data_filter_sum[k] >> 4;  // ÷ 16
  temp[k] = raw_data_filter[k];
}

小波动（≤ 10）当噪声，做“新值占 1/16”的平滑；大变化（手指真的在动）立刻跟上，不拖后腿。÷16 用右移 4 位，不用除法（M0 没有除法指令，见 ⑤）。两个 raw_data_filter 数组是函数里的 static，所以记得上一次。

⑤ 算按下程度：Hall_CalculateNode()（my_misc.c:288~327）

if(顶部 ≥ 底部 || 底部 − 顶部 < 100) return 0;   // 两条线还没拉开，一律当 0
if(值 ≤ 顶部) tmp = 0;
else if(值 ≥ 底部) tmp = 255;
else
{
  if(基线变了) step = (1 << 21) / (底部 − 顶部);     // 只在基线变化时做一次除法
  tmp = ((值 − 顶部) * step * 255) >> 21;          // = (值 − 顶部) × 255 ÷ (底部 − 顶部)
}
return nodeCaliTable[tmp];                         // 0~255 查表成 0~100

本质就是一个比例：(值 − 顶部) ÷ (底部 − 顶部)，换算成 0~255，再查表变成 0~100。两个工程技巧：

  • 定点数代替除法：Cortex-M0 没有硬件除法指令，每次除法都要调库函数（几十个时钟）。这里把 1/(底部 − 顶部) 预先算成 step = 2²¹ / 差，存在 static 里；之后每毫秒只做乘法和右移 21 位。基线不变就不再除。
  • 查表：nodeCaliTable[256]（my_misc.c:16~44）IRPT_V4 版接近一条直线（每 2.55 格 +1）；霍尔板型那版是弯的，用来修正磁场的非线性。想调整“按到一半算几段”，改这张表就行。

⚠️ 两条线没拉开（差 < 100）时永远返回 0，这时怎么按都不会触发。开机学完顶部基线后正是这种状态，要靠 ⑦ 的底部基线学习把它拉开。

⑥ 快速触发：Hall_HandleKeyRapidTrigger()（my_misc.c:330~396）

if(现在是按着)
{
  if(段位 == 0)                                      → 松开
  else if(段位 > 记录的最深)  记录的最深 = 段位;     // 还在往下按，跟着记
  else if(记录的最深 > 段位 + rt_release)            → 松开（从最深处回弹够多）
}
else // 现在是松着
{
  if(段位 ≥ 100)                                     → 按下（按到底）
  else if(段位 < 记录的最浅)  记录的最浅 = 段位;     // 还在往上抬，跟着记
  else if(段位 ≥ 记录的最浅 + rt_press 且 段位 ≥ ap)  → 按下（从最浅处按下去够多，且过了触发点）
}

普通按键是“过了某个固定深度就算按下”。快速触发（Rapid Trigger）是电竞鼠标 / 键盘的做法：只看“相对最近的最浅 / 最深点移动了多少”。好处：按住不放、稍微抬一点就能松开，再稍微压一点又能按下，连点更快。

三个参数（段位单位，0~100）：ap_value 触发点（默认 10）、rt_press_value 按下距离（默认 30）、rt_release_value 松开距离（默认 20）。默认值在 my_misc.h:42~44，实际值开机由 Hall_UpdateParam()（my_misc.c:101）从 EEPROM 参数 xgAllParam 覆盖，GUI 能改。current_node_update[] 是函数内 static，记着“最深 / 最浅”。

⑦ 校准两条基线（my_misc.c:162~286）

顶部基线 Hall_CalibrateTopBaseline()：只在松着的时候调。当前值 比 顶部 低 20 以上、持续 300 ms → 顶部 −20；比顶部低一点、持续 100 ms → −5；比顶部高一点（≤ 20）、持续 100 ms → +2。按着时三个计数器清零。作用：温度、环境光慢慢变化时，“没按”的数值会漂，顶部基线慢慢跟着走。

底部基线 Hall_CalibrateBottomBaseline()：当前值 比 底部 高 80 以上、持续 30 ms → 底部 +60；高 20 以上、持续 30 ms → +10。只会往大走，不会往回缩；按住超过 100 ms 后就不再学（避免长按时乱改）。作用：学出“按到底”是多少。
由此推出：每次按下，只有被判定按下后的前 100 ms 在学，所以底部基线要点好几次才学到真正的“按到底”。学到之前，底部偏浅，段位会偏大（按一半就显示 70、80）。模拟器“开机 + 第一次点击”里可以看到底部基线一次次往上走。

⚠️ 由此推出：开机后的第一次点击要“按住一会儿”
开机学完后底部 = 顶部，⑤ 一律返回 0，不会触发。第一次按下去，当前值比底部高很多，每持续 30 ms 底部 +60；大约 60 ms 后两条线拉开到 ≥ 100，⑤ 开始算出段位，此时当前值已经 ≥ 底部，段位 = 100，⑥ 判定按下。所以开机后第一下快速轻点可能不响应，按住约 60 ms 以上才行；之后的点击都正常。模拟器里选“开机 + 第一次点击”能看到。这是从代码推出来的，要上板验证。

5/8坑和值得注意的地方

位置问题影响
my_adc.c:113 vs 108、117超时返回 −2 的那条路，既没停止转换（108 行），也没把 SEL 位清掉（117 行）。下一次读另一个通道时，SEL 里会同时有两位是 1；手册要求软件启动模式下只能选一个通道只有超时才发生，概率低；但一旦发生，下一次读数可能读错通道。修法：超时返回前也清 SEL

6/8T1A

T1A 的左右键换成 GTRY164 霍尔芯片（SPI），不再需要 ADC 读按键；PIO0_13 / 14 改作线圈 PWM，PIO0_19 改作滚轮信号（T1A 适配清单）。所以 T1A 上：MyADC_Init() 的两次调用、IR_EN 的初始化、LR_GetState() 里的 ADC 分支都要去掉。my_adc.c 这个驱动本身可以留着，以后如果要量电池电压之类的模拟量，按第 3 节的做法加通道。

7/8💡 想法上

1. 读驱动代码，一行对一个寄存器字段
这一页的方法可以用在任何外设上：每看到一句 XXX->REG |= / &= …，就问三件事：哪个寄存器？哪几位？手册里这几位是什么意思？把答案写在旁边。读完一个驱动，你就有了一张“这个外设被设成了什么样”的表。
2. 错误处理的路径，最容易漏掉收尾
上面第一个坑就是典型：正常路径最后会清 SEL，超时提前 return 的路径却没清。以后写“中途可能返回”的函数，检查一下：每一个 return 之前，该恢复的东西都恢复了吗？

8/8小测

记住：开机 MyADC_Init()：PDRUNCFG bit4 清 0（上电）、SYSAHBCLKCTRL bit13 置 1（时钟）、CLKDIV = 15（48 MHz ÷ 16 = 3 MHz）；引脚 IOCON 去上下拉、ADMODE 清 0（模拟）、FUNC = 2（AD）。每次 MyADC_GetValue()：停 → 选 SEL → 读一次 DR 清 DONE → START = 001 → 每 2 µs 看 DONE → 取 DR 第 15~6 位 → 清 SEL。

本页新词

CLKDIVADC 时钟分频：ADC 时钟 = 系统时钟 ÷（CLKDIV + 1），不能超过 4.5 MHz
SELCR 低 8 位，选哪个通道
STARTCR 第 26~24 位，写 001 = 立刻开始转换
DONEDR 第 31 位，转换完成；读一次 DR 自动清掉
ADMODEIOCON 第 7 位：0 = 模拟（断开数字输入电路），1 = 数字
BURST连续转换模式（本项目没用）
