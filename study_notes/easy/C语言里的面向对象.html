C 语言里的面向对象

C 没有 class，但面向对象是一种组织代码的方式，不是某种语言的专利。这一页用本项目里已经存在的代码，说明 C 怎么做到“对象、方法、封装、多态”，再看一处本该这么写、却复制粘贴了 4 份的代码，最后说 T1A 可以怎么用。

1/6🧭 本质

面向对象的本质：把“一份数据”和“操作这份数据的函数”绑在一起，并且这份数据可以有好几个实例。

在 C 里，这件事用 4 样东西拼出来：

面向对象的概念C 里怎么做本项目里现成的例子
类 / 对象：一种东西的模样，和具体的某一个typedef struct 定义模样；定义几个这种类型的变量，就是几个对象MyADC_ts 是模样，leftAdcInst、rightAdcInst 是两个对象（my_adc.c:27、33）
方法：属于这个对象的操作普通函数，第一个参数传对象的指针（相当于别的语言里的 this / self）MyADC_GetValue(MyADC_ts *p, …)：传左键的指针就读左键，传右键的就读右键
封装 / 私有：外面不能随便碰内部数据在 .c 文件里用 static 藏起变量，头文件只公开函数my_tick.c 里 static uint32_t mySysTickMs，外面只能调 MyTick_GetTickMs() 读，改不了
多态：同一句调用，不同对象有不同行为函数指针：存一个“该调哪个函数”的地址，运行时再决定USB_P_EP[]（usbuser.c:165）：USB 中断里同一句 USB_P_EP[m](event)（usbhw.c:1408），m 不同就调不同端点的处理函数

“继承”在 C 里很少硬做，常用组合代替：一个结构体里装着另一个结构体。比如 TI_DRV8833_ts 里装着一个 TI_DRV8833_IO_ts io（inc/TI_DRV8833.h:33），AllConfig_ts 里装着触发、线圈、刹车 5 个配置结构体。

2/6本项目里做得好的例子：带“句柄”的驱动

句柄（handle）：指向某个对象的指针。函数只拿句柄，不关心具体是哪一个，所以同一份代码能服务多个实例。

// src/my_adc.c:27~40  —— 两个对象
MyADC_ts leftAdcInst  = { .ch = 2, .port = LB_ADC_PORT, .pin = LB_ADC_PIN, .pFuncReg = &(LPC_IOCON->LB_ADC) };
MyADC_ts rightAdcInst = { .ch = 3, .port = RB_ADC_PORT, .pin = RB_ADC_PIN, .pFuncReg = &(LPC_IOCON->RB_ADC) };
MyADC_ts *pLeftAdcHandle  = &leftAdcInst;
MyADC_ts *pRightAdcHandle = &rightAdcInst;

// 一个方法，服务两个对象（button.c:320~321）
ret  = MyADC_GetValue(pLeftAdcHandle,  &leftVal);
ret |= MyADC_GetValue(pRightAdcHandle, &rightVal);

5/6💡 想法上：分寸


1. 第二个出现时，再抽象
只有一个线圈时，写 Ele_LeftKeyPressProcess() 完全没问题。等出现了第二个实例（右线圈），或者第二种实现（红外 / 霍尔），再把它变成“对象 + 句柄”或“接口 + 函数指针”。提前为想象中的需求抽象，代码会变复杂却换不来好处。


2. 在 M0 上有代价，但通常很小
多传一个指针参数、多一次通过指针取成员，每次多几条指令；函数指针调用不能被内联。按键每 1 ms 才处理一次，这点开销可以忽略。真正要小心的是中断里、每微秒都要跑的代码。


3. 先认出现有代码里的“对象”
这个项目里已经有很多“对象”：leftEle、leftAdcInst、buttonScan_stru、g_USBHW_Setting，连 LPC_GPIO 都是一个“外设对象”（指向 0x5000 0000 的结构体指针）。读代码时把它们当成对象看：它有哪些数据？哪些函数是它的方法？比把一堆全局变量和函数分开记容易得多。



6/6小测




记住：C 的面向对象 = struct 装数据 + 第一个参数传对象指针的函数 + static 藏私有 + 函数指针做多态。本项目的 MyADC_ts、TI_DRV8833_ts、USB_P_EP[] 是现成的好例子；左右线圈的 4 个函数是可以合并的反例。


本页新词




实例按某个结构体模样定义出来的一个具体变量


句柄（handle）指向某个对象的指针，函数靠它知道操作的是哪一个


函数指针存着一个函数地址的变量，调用它就调到那个函数


接口一组函数指针打包成的结构体，规定“能做哪些事”，不规定“怎么做”


组合一个结构体里装着另一个结构体
