GPIO 与引脚配置

1/7一根引脚归两个部门管

每根引脚都要在两个地方设置：

部门管什么地址手册
IOCON（引脚配置）这根脚给谁用（GPIO、ADC、SPI…）；电气特性：上拉、下拉、模拟/数字、开漏0x4004 4000，每根脚一个寄存器第 7 章
GPIO（通用输入输出）当它是普通 IO 时：输入还是输出（DIR）、读电平（PIN）、输出高/低（SET/CLR）0x5000 0000，每个端口一组寄存器，1 位对应 1 根脚第 9 章
上拉 / 下拉：芯片内部一个约几十 kΩ 的电阻，把引脚“轻轻地”拉到 3.3 V（上拉）或 0 V（下拉）。外面没东西驱动时，引脚就是这个电平；外面一驱动，就听外面的（第 1 课的按键电路）。
开漏：输出时只能把引脚拉到 0 V，不能主动输出 3.3 V。输出“1”时引脚只是松开，要靠外部上拉电阻才会变高。
悬空：引脚既没被外面驱动，也没有上下拉，电平不确定，读出来可能是 0 也可能是 1。
动手 · 引脚模拟器：改设置，看引脚电压和读到的值

GPIO 一句话来龙去脉
开机时所有脚都是“输入 + 上拉”，只有 PIO0_11~14 归 JTAG、PIO0_4/5 是没有上拉的开漏脚。InitGPIO() 把 JTAG 的 4 根脚收回来当 GPIO，再按 IRPT_V4 的接线把每根脚设成输入或输出，输出脚一律“先设电平再切方向”防毛刺。平时：按键扫描每 1 ms 读一次 PIN；SPI 收发前后用 CLR/SET 拉低拉高片选；振动时用 SET/CLR 控制线圈脚。电脑休眠时，中键、侧键、DPI 键被设成“组中断”，按任意一个就把芯片叫醒。

4/7📖 手册导读：第 7 章 IOCON（第 80~127 页）

这一章前面 4 页讲原理，后面四十多页是“每根脚一张表”。按下面的顺序读：

📖 p.80 · 7.1 How to read this chapter
先看这一节的表：不同封装可用的引脚不一样。我们的芯片是 HVQFN33 封装，只有 PIO0_0~PIO0_23 加上 PIO1_15、PIO1_19。

9 个小节，每节讲 IOCON 寄存器里的一种设置。全部读一遍，每节只有几行：
7.3.1 Pin functionFUNC 位。重点句：“The DIR registers have no effect for peripheral functions.”

7.3.6 Open-drain mode开漏
7.3.7 Analog mode模拟模式（ADC 用，第 7 课）
7.3.8 I2C modePIO0_4/5 的特殊之处
7.3.9 RESET pin复位脚
问题 1：MODE 的复位值是什么？“中继模式（repeater）”是什么意思？7.3.2 第一段：“The default value is pull-up enabled.” 复位后是上拉。中继模式：引脚是高就开上拉，是低就开下拉，让没人驱动的引脚保持最后一次的电平，不至于悬空。
问题 2：一根脚选了 SPI 功能后，DIR 寄存器还管它的方向吗？不管。7.3.1：“For any peripheral function, the pin direction is controlled automatically … The DIR registers have no effect for peripheral functions.” 所以 SPI 的三根线不用设 DIR，只有当普通 GPIO 时 DIR 才有用。
📖 p.84~86 · Table 75 Register overview
所有引脚寄存器的总表：名字、地址、复位值。注意大部分是 0x0000 0090，有几个不一样。
问题 3：0x90 拆开是什么意思？哪几根脚的复位值不是 0x90？0x90 = 1001 0000：FUNC = 000，MODE = 10（上拉），ADMODE（bit7）= 1（数字）。PIO0_4、PIO0_5 是 0x0000 0080：它们是 I²C 脚，bit7:3 是保留位，没有 MODE，所以没有上拉（第 89 页 Table 80 会讲）。你在表里还能找到其它和 0x90 不一样的，自己数一数。
📖 p.87 Table 77（PIO0_1）· p.89 Table 80（PIO0_4）· p.94 Table 87（TDI_PIO0_11）
翻开这三张表并排比较。它们都是“一根脚的寄存器”，但位的定义不一样。
问题 4：这三张表最大的不同是什么？ PIO0_1：普通脚，FUNC = 0 就是 GPIO，有 MODE、HYS、INV、OD。
PIO0_4：I²C 脚，FUNC = 0 是 GPIO（open-drain），没有 MODE、没有 OD，bit9:8 是 I2CMODE。
TDI_PIO0_11：JTAG 脚，FUNC = 0 是 TDI，要写 1 才是 GPIO；还有 ADMODE（它能当 AD0）。
所以规矩是：改任何一根脚之前，先查它自己那张表。

📖 p.153 · 9.2 Basic configuration：GPIO 的“七步”：时钟 bit6（端口）、bit19（引脚中断）、组中断的时钟和唤醒设置。

问题 7：往 SET 里写一个数，写成 0 的位会怎样？为什么代码用 SET[0] = (1<<20) 而不是 |=？写 0 的位不受影响，只有写 1 的位变高。所以直接用 = 就只改那一根脚，不需要先读出来。这样更快，也不怕“读出来还没写回去时被中断改了”。CLR 同理。
问题 8：9.6.2 说，写引脚要真正生效需要满足哪两个条件？1）这根脚在 IOCON 里选成了 GPIO；2）它在 DIR 里被设成了输出。两个条件有一个不满足，“写引脚”就没有效果。但输出寄存器里的值还是会被记下（可以先写值、后切方向，这正是防毛刺的原理）。
问题 9：读 PIN 寄存器，读到的是什么？引脚是输出时也能读吗？读到的是引脚上实际的电平，不管它是输入还是输出、是不是被别的外设占用（9.6.2 最后一段：“returns the state of pins, regardless of their direction or alternate functions”）。
问题 10：组中断的标志怎么清？去 p.161 Table 151 找。CTRL 寄存器 bit0 INT：“This bit is cleared by writing a one to it. Writing zero has no effect.” 写 1 清零。代码 LPC_GPIO_GROUP_INT0->CTRL |= 0x1;（GPIO.c:268）就是在清它。

7/7容易出错的地方、你能改什么、T1A

容易出错

JTAG 脚忘了改 FUNCPIO0_11~14 复位后不是 GPIO，读写都没用。要先 FUNC = 1。PIO0_10、PIO0_15 是 SWD 调试口，不要改，否则下载器连不上。
输出脚先切方向再设电平切成输出那一刻会先输出旧值 0，产生毛刺。NCS 出毛刺，传感器会以为被选中。
ADC 脚开着上拉上拉会把电压往 3.3 V 拉，读数不准。
拿 PIO0_4/5 当普通输出真开漏，输出 1 时只是松开，需要外部上拉才会变高。IRPT_V4 的线圈 PWM 就接在这两根脚上，板上是否有上拉要问杰哥 ⚠️（1-3 课）。
对 SET/CLR 用 |=能用但多余，还会先读一次；直接 =。
引脚号对错原理图上的是封装脚号（第 3 脚），代码里的是端口号（PIO0_1）。用第 8 章 Table 135 对照。

你能改什么：比如加一个按键

  1. inc/my_board.h：IRPT_V4 分支里定义新按键的端口和引脚号
  2. src/GPIO.c IRPT_V4 分支：设成输入（如果是 PIO0_11~14 要先改 FUNC）
  3. inc/button.h：把它加进 BUTTON_PORT0 的掩码，定义它在报文里的位
  4. app/button.c：Button_GetState() 里加上它的位置换算（第 17 课）
  5. src/wnDrv_Pmu.c：要它能唤醒电脑，就加进组中断的 ENA

T1A 上的变化

T1A 几乎每根脚的用途都变了（03_T1A适配清单.md 第一节）。和本课最相关的几条：

PIO0_4 / PIO0_5不再接线圈，改做 I²C 接充电芯片（这才是它们本来的用途）
PIO0_13 / PIO0_14改接线圈 PWM：先改 FUNC = 1，而且它们是普通推挽脚，IOCTRL_NoPull / IOCTR_PushPull 这次真的会起作用
按键四个按键换了引脚，而且外部有 47 kΩ 上拉；BUTTON_PORT0 掩码和唤醒的 ENA 都要改
PIO0_1改接充电芯片的 /CE，不再是按键

小测验

这一课你只需要记住：一根脚 = IOCON（给谁用、上下拉）+ GPIO（方向、读写）。开机全是“输入 + 上拉”，PIO0_11~14 是 JTAG 要改 FUNC。输出脚先设电平再切方向。读用 PIN，写用 SET/CLR（写 1 才生效）。改任何一根脚之前，先查它自己的那张 IOCON 表。
