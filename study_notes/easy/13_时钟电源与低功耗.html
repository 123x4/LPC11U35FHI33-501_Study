时钟、电源与低功耗

前面每一课的“② 时钟”都只说了“开时钟”，这一课讲时钟从哪来：芯片怎么从一颗 12 MHz 晶振变出 CPU 和 USB 要的 48 MHz。后半课讲省电：电脑睡觉时，鼠标怎么把自己降到几百微安。照例先场景、再代码、手册最后。

📍
在地图上：第 ① 列 时钟、电源管理 ↔ 第 ③ 列 开机、挂起 / 唤醒。手册：第 3 章（系统控制：时钟、PLL、电源配置）、第 4 章（PMU）、第 5 章（ROM 里的电源 / 时钟函数，这个项目没用）。

1/9时钟是什么：芯片的心跳

芯片里所有东西都按一个“节拍”干活：CPU 每拍执行一点指令，定时器每拍加一，SPI 每拍移一位。节拍越快，干活越快，也越费电。这个节拍就是时钟。芯片里有好几个“心脏”，再经过倍频、分频，分给不同的人：

动手 · 时钟树：点左边的选择开关，看 CPU 和 USB 拿到多少
IRC：芯片内部的 12 MHz 振荡器，不用外接零件，但不够准（±1%）。上电后默认用它。
晶振（系统振荡器）：板子上外接的 12 MHz 晶体（XTALIN / XTALOUT 两个脚），很准。USB 必须用它（第 10 课手册 11.4.7）。
PLL：锁相环，把输入频率乘上去（12 × 4 = 48 MHz）。
分频器：把频率除下来，给各个外设。

2/9先看场景：时钟和电源在什么时候变

场景发生什么代码
A 刚上电芯片用 IRC 12 MHz 跑：ROM 启动程序、公司 bootloader、我们程序的开头，都在 12 MHz 下运行芯片默认
B 开机设时钟打开晶振 → 系统 PLL × 4 → CPU 切到 48 MHz；再打开 USB PLL，给 USB 单独一路 48 MHzInitSystemOSC()、InitUSBOSC()（device.c:420、429）

3/9PLL：12 MHz 怎么变成 48 MHz

原始代码（OSC.c:29~56，InitSystemOSC()）：

	LPC_SYSCON->SYSOSCCTRL |= (OSC_Freqrange<<1) ;					//Frequency Range
	LPC_SYSCON->PDRUNCFG &= ~(0x1<<5) ;								//Crystal oscillator powered
	for( OSCI = 0; OSCI < 0x100; OSCI++ ) ;
	//-----
	LPC_SYSCON->SYSPLLCLKSEL = SysOSC ;								//Select System PLL clock source
	LPC_SYSCON->SYSPLLCLKUEN = 0x01 ;
	LPC_SYSCON->SYSPLLCLKUEN = 0x00 ;
	LPC_SYSCON->SYSPLLCLKUEN = 0x01 ;
	while ( !(LPC_SYSCON->SYSPLLCLKUEN & 0x01) ) ;
	//-----
	LPC_SYSCON->SYSPLLCTRL = ((SysPSEL<<5) | SysMSEL) ;				//Feedback divider value
	LPC_SYSCON->PDRUNCFG &= ~(0x1<<7) ;								//System PLL powered
	while ( !(LPC_SYSCON->SYSPLLSTAT & 0x01) ) ;
	//-----
	LPC_SYSCON->MAINCLKSEL = 0x03 ;									//Select Clock source for main clock(0:IRC 1:PLL In 2:WDT 3:PLL Out)
	LPC_SYSCON->MAINCLKUEN = 0x01 ;
	LPC_SYSCON->MAINCLKUEN = 0x00 ;
	LPC_SYSCON->MAINCLKUEN = 0x01 ;
	while ( !(LPC_SYSCON->MAINCLKUEN & 0x01) ) ;
	//-----
	LPC_SYSCON->SYSAHBCLKDIV = AHBDiv ;								//System AHB clock divider values

调用链：Device_Init()（device.c:420）→ InitSystemOSC( MAIN_SEL , PSEL , MSEL , SYS_AHB_DIV_VAL)。宏展开（inc/OSC.h:15~18）：InitSystemOSC(1, 1, 3, 1)。四段分别是：①给晶振通电 ②PLL 的输入选晶振 ③设倍数、给 PLL 通电、等它锁定 ④主时钟切到 PLL 输出。

“写 1、写 0、再写 1”（UEN 寄存器）：改时钟来源后，必须这样“拨一下”开关新设置才生效，是芯片规定的（手册 MAINCLKUEN 表）。
锁定：PLL 刚通电时频率不稳，要等 SYSPLLSTAT 的 LOCK 位变 1 才能用。
动手 · 自己调 MSEL、PSEL，看结果合不合法

规则来自手册 3.10.4：输出 = M × 12 MHz；内部振荡器 FCCO = 2 × P × 输出，必须在 156~320 MHz 之间；CPU 最高 50 MHz。项目选 M = 4、P = 2：输出 48 MHz，FCCO = 192 MHz，合法。

5/9省电：芯片的 5 种状态

动手 · 选一种状态，看哪些东西还开着、耗多少电

电流是数据手册里芯片自己的典型值（3.3 V、25 °C），不含传感器、线圈、LED。USB 规定挂起时整个鼠标最多 500 µA（第 10 课手册 11.4.5），芯片深度睡眠就用掉约 300 µA，余量不大。

WFI（Wait For Interrupt）：一条 CPU 指令，执行后 CPU 停下，等中断来了再继续。
SLEEPDEEP：内核 SCR 寄存器里的一位，决定 WFI 是浅睡还是深睡。
PDSLEEPCFG / PDAWAKECFG：深度睡眠时哪些模拟电路保持通电 / 醒来后哪些自动通电。

6/9时钟和电源的一生：生命周期图

一句话来龙去脉
上电后芯片用内部 12 MHz（IRC）。Device_Init() 先开看门狗，然后 InitSystemOSC()：开晶振 → 系统 PLL × 4 → 主时钟切到 48 MHz；再 InitUSBOSC() 给 USB 单独一路 48 MHz。之后各外设自己开时钟、设分频。电脑挂起时，wnDrv_Pmu_Init() 关掉 IRC、ADC、BOD、看门狗振荡器，设按键为唤醒源；wnDrv_Pmu_Sleep() 设好醒来后的上电配置，进深度睡眠。按键把它叫醒后，重新 InitSystemOSC() 回到 48 MHz。

任务 1：第 3 章找 CGU block diagram（时钟生成单元框图），和第 1 节的时钟树对照。
答案Fig 7，p.20。左边是 IRC、系统振荡器、看门狗振荡器；中间是系统 PLL、USB PLL 和 MAINCLKSEL 选择器；右边是 SYSAHBCLKDIV 和各外设的分频器。和第 1 节的图一样，只是多了 CLKOUT 等这个项目没用的路。
任务 2：找 SYSPLLCTRL 和 3.10 节的 Frequency selection，自己验算 48 MHz 和 FCCO。
答案Table 9，p.24：MSEL（4:0）、PSEL（6:5）。3.10.4，p.53~54：公式 Fclkout = M × Fclkin = FCCO ÷ (2 × P)；FCCO 156~320 MHz。M = 3 + 1 = 4，P = 2：48 MHz，FCCO = 2 × 2 × 48 = 192 MHz。
任务 3：找 MAINCLKSEL，看 0~3 四个值分别选什么。
答案Table 21，p.30：0 = IRC；1 = PLL 的输入；2 = 看门狗振荡器；3 = PLL 的输出。代码写 3。紧跟着的 MAINCLKUEN 表说明了为什么要“写 1、写 0、写 1”。

答案Table 50，p.47。深度睡眠：PLL、晶振、ADC、所有数字外设、USB 都关；IRC 开着但不输出；Flash 待机；BOD 和看门狗振荡器可以自己选（由 PDSLEEPCFG 决定）。
任务 5：找 3.9.4.2 Programming Deep-sleep mode 和 3.9.4.3 Wake-up from Deep-sleep mode。

任务 6：第 4 章找 Power control register（PCON）。PD 位写 0、1、2、3 分别是什么？
答案Table 54，p.56：0x0 = 睡眠或深度睡眠（看 SLEEPDEEP）；0x1 = 深度睡眠；0x2 = 掉电（Power-down）；0x3 = 深度掉电。项目写 1（BIT0）。
任务 7：数据手册里找各模式的 supply current（IDD），对照第 5 节。
答案数据手册 Static characteristics 表的 IDD 行：运行 12 MHz 约 2 mA、50 MHz 约 7 mA；睡眠约 1 mA；深度睡眠约 300 µA；掉电约 2 µA；深度掉电约 220 nA（都是典型值）。

9/9容易出错、你能改什么、T1A

进深度睡眠前没切到 IRC ⚠️见第 7 节。问杰哥。
晶振等待时间很短OSC.c:36 只空转 256 次（在 12 MHz IRC 下约几十微秒）就去用晶振。晶振起振通常要更久，不过后面还要等 PLL 锁定（OSC.c:46），PLL 没锁上不会往下走，实际有保护。
改主频会牵一发动全身SSP、ADC、定时器、IAP 的 MCU_OSC/1000、USB 以外的所有分频都按 48 MHz 算的（第 4 节）。
USB 时钟必须准USB PLL 输入必须是晶振（USBPLLCLKSEL = 1，OSC.c:63），不能换成 IRC。
挂起后 BOD 不再打开 ⚠️第 12 课说过：wnDrv_Pmu.c:61 关掉以后，醒来没人打开。
挂起时外部器件还在耗电芯片约 300 µA，加上 PAW3950 休眠电流（它自己会进 Rest 模式，最低约 6 µA）、霍尔 / 红外电源（IR_EN 挂起时仍是高电平，第 7 课）……整机能不能压在 500 µA 以内，要实测。

你能改什么

  • 挂起时多关点东西：在 wnApi_Events_Suspend_Handler() 里关传感器、关红外电源（IR_EN 拉低）、关 ADC，醒来再打开。
  • 补上手册第 4 步：睡前调用现成的 clockinit()（要和杰哥确认后再改，并测试唤醒）。

T1A 上

晶振还是 12 MHz，时钟部分不用改。要注意：T1A 有电池和充电芯片 BQ21128，如果以后做无线或者“不插 USB 也要待机”，低功耗就从“USB 规定的 500 µA”变成“电池能撑多久”，深度睡眠甚至掉电模式（2 µA）都要认真设计。新增的霍尔芯片 GTRY164、R-DIP 编码器睡眠时怎么关，也要在挂起函数里加。

小测验

这一课你只需要记住：上电默认用内部 12 MHz（IRC）；InitSystemOSC() 打开外接 12 MHz 晶振，用系统 PLL 乘 4 得到 48 MHz 给 CPU；USB 另有一个 PLL，也是 48 MHz。所有外设的频率都从 48 MHz 分出来。挂起时进深度睡眠（PCON = 1、SLEEPDEEP = 1、WFI），芯片约 300 µA，按键（GINT0）唤醒后重新设时钟。
