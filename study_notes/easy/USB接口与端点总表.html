USB 接口与端点总表

鼠标在 USB 上有哪些“通道”、每条通道传什么、谁发谁收、代码在哪，都在这一页。点下面任何一个端点（或表里任何一行），所有表格里和它有关的行都会一起亮起来。

一眼看全：1 个设备 → 3 个接口 → 5 个端点

表 5 · 四个场景对照

场景用到的端点过程
0 插线（一次）EP0Windows 要走全部说明书 → 认出接口 0 是鼠标、1 是键盘、2 是厂商自定义（开条通道给 GUI）
1 移动、点击、滚轮（每 1 ms）EP1鼠标放 8 字节 → Windows 鼠标驱动解析 → 光标动。GUI 没开也一样
1′ 宏按键EP2（也可能 EP1）鼠标假装键盘发键码 → Windows 当成有人敲键盘
2 GUI 改设置EP4GUI 发 64 字节命令 → Windows 原样转交 → PC_Communicate() 执行、保存
3 GUI 读设置EP4 → EP3GUI 发“给我设置” → 鼠标从 EP3 一包包回 64 字节 → GUI 显示
记住三句话：① EP1、EP2 是给 Windows 的（光标、键盘），格式由报告描述符说明，Windows 自己解析。② EP3、EP4 是 GUI 和鼠标的私聊，每包 64 字节，Windows 只转交，每个字节的意思由公司协议定。③ EP0 只在插线时忙，项目代码不碰。

T1A 会动哪里

  • 新协议 + GUI：主要改表 4 的 GUI 命令 / 回复格式（EP3、EP4）和 PC_Communicate()。通道本身（64 字节进出）多半不用改。
  • VID / PID：如果新产品换号，改 inc/usbdesc.h:39~40。
  • 按键数量：鼠标包里只有 5 个键位。T1A 如果要报告更多键，表 4 的鼠标包和描述符要一起改。
