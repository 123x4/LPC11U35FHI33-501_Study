一句话：button.c 和 scroll.c 负责“看”（读按键、读滚轮），custom.c 负责“翻译”（这个键代表什么功能），翻译完交给 src/device.c 发给电脑。optical_3325.c 是上一代传感器的驱动，现在只剩一个延时函数在用。

    button.c 里的“霍尔”
    变量叫 hall_spi_rx，但 IRPT_V4 的左右键是红外：LR_GetState() 把两路 ADC 值塞进这个数组，再交给 ProcessRecvSampleRawData()（my_misc.c:418）。名字是从别的板型（霍尔版）沿用来的。
    文件末尾 9 个 Hall_* 函数（787~917 行）是给霍尔板型写的：两颗霍尔芯片菊花链接在 SSP 上、没有片选，靠在 SCLK 脚上打一个特殊脉冲（Hall_CLK_Command_SET()）发命令。IRPT_V4 下编进去了但没人调用。T1A 的 GTRY164 也是菊花链、没片选，这些函数是很好的参考，先别删。
    


    6/8custom.c：“改键 + DPI + 配置档”的翻译官
    

    前世：这是老 GUI 时代的“自定义设置”引擎。全局变量 gloabSetting（拼写原样）里存着 2 套配置档（MODE_NUM = 2），每套有：10 个键的功能、4 档 DPI、回报率、灯效。老 GUI 能改这些，改完存进 EEPROM（第 11 课的老区域 0x000~0xB84）。
    

    今生：本项目把“开机从 EEPROM 读回设置”“灯效”“产线测试”都注释掉了（和 M300S 比，改了 12 个函数），所以每次开机都是默认值。但翻译引擎还在每次按键时运行：Custom_HandleKey() 是热路径。

    按 DPI 键 → DealSpecialFunctionKey() → Custom_Dpi_Deal(CYCLE_DPI) → Custom_Set_DPI(档位, 存=TRUE, 发=TRUE, …)：
    ① 真正改传感器的那句 optical_set_dpi() 被 #if ((!defined(IRPT_V4)) …) 关掉了（custom.c:396~398）。PAW3950 一直是开机设的 1600（PAW3950.c:398）。
    ② 但每按一次都写一次 EEPROM（OperateFlash_Store_ModeSetting() → GtechFlash_WriteBytes() → Chip_EEPROM_Write()），写的时候会关中断（第 11 课）。
    ③ 还会从 EP3 给 GUI 发一包“DPI 变了”。
    也就是说：按 DPI 键手感上没变化，却在悄悄写 EEPROM。整理代码或做 T1A 的 DPI 功能时要处理这里。
    

    另一个要知道的：升级入口
    老 GUI 发“升级”命令时，PC_Communicate() 调 Bootloadable_Load()（custom.c:76）：往 RAM 0x10001F00 写一个 0xAA，再软件复位。公司 bootloader 开机看到“软件复位 + 0xAA”，就留在升级模式（见 0-3 课“公司 Bootloader”）。这个函数不能删。
    


    7/8optical_3325.c：上一代传感器的驱动，只剩一个延时
    

    前世：文件头写着 “Copyright 2003-2006, Cypress Semiconductor”“interface to the Avago optical chip using an SPI port on the PSoC”：Cypress 给 PSoC 芯片做的光学鼠标参考代码，后来被开发者改成驱动 PixArt 3325 / 3327 传感器。和 M300S 比只改了两行空白和注释。
    

    今生：IRPT_V4 用 PAW3950（src/PAW3950.c），这个文件里的传感器函数全没人调用。还在用的只有：
    

    void TimerDelayMsec(uint32_t t_count)
{
	DrvDelay(t_count *10);//delay *10 = 1ms
}
    

    和一个变量 optical_double_flag（custom.c 写它，但也没人读）。TimerDelayMsec() 被 device.c、usb.c、test.c 调用，是个“忙等 N 毫秒”的延时。
    

    为什么死代码也占 Flash
    Keil 的链接器以“段”为单位取舍。这个文件的所有函数在同一个代码段里，只要 TimerDelayMsec（12 字节）被用到，整段 720 字节都留下，还顺带拉进几个浮点运算库函数（optical_get_report() 里用了 float / double）。以后整理时，可以把 TimerDelayMsec 挪到 Timer.c，再把这个文件移出工程。这一步要改工程，按规矩先编译、实测、问杰哥。

    本页新词
    

    

    正交编码器两根线轮流变化，看谁先变来判断方向（滚轮用）
    

    消抖开关按下时电平会抖几下，要等它稳定一段时间再认
    

    键位 / 功能编号（id）物理键的序号 / 这个键代表的功能，查表把前者翻译成后者
    

    配置档（profile）一整套设置（键位、DPI、灯效），可以存好几套切换
    

    菊花链几颗芯片串成一串：上一颗的输出接下一颗的输入，共用一套 SPI，没有片选
    

    热路径每次按键都会走到的代码，改它要格外小心
