ADC：把电压变成数字

GPIO 只能分清“高”和“低”。左右键是“按了多深”，电压在 1 V 到 2.6 V 之间连续变化，必须把它量成一个数。这就是 ADC 的工作。这一课从原理讲到初始化、每 1 ms 的读取、手册第 19 章，把 ADC 讲完整。

1/7ADC 是怎么量电压的

ADC（Analog-to-Digital Converter，模数转换器）：把 0 V 到 VDD（这里是 3.3 V）之间的电压，量成 0 到 1023 之间的一个整数。

可以把它想成一把 1024 格的尺子，量的是电压：每一格 3.3 V ÷ 1024 ≈ 3.2 mV。读数 317，就是电压大约在第 317 格：317 × 3.3 ÷ 1023 ≈ 1.02 V。

它怎么量：逐次逼近，就是“猜数字”

这颗芯片的 ADC 叫“逐次逼近型”。它量电压的方法，和你玩“我心里想一个 0~1023 的数，你猜，我只说大了还是小了”一模一样：每次猜中间，一次排除一半，10 次就一定猜中。每猜一次大约用 1 个时钟，加上开头采样，一共 11 个时钟。

动手 · 拖动电压，再一步步点“猜下一位”

每一位“猜”的时候，ADC 内部用一个小的数模转换器产生“中间电压”，和引脚电压比大小。这些全是芯片自己做的，程序只需要说“开始”，然后等“完成”。

2/7这个项目怎么找到“左键那一路”

ADC 有 8 个输入（AD0~AD7），每次只能量一个。左键接 AD2（PIO0_13），右键接 AD3（PIO0_14）。my_adc.c 把“一路 ADC 需要的信息”装进一个结构体，左右各一个：

/* inc/my_adc.h:18 */
typedef struct {
  uint8_t ch;                   // 第几路 ADC
  uint8_t port;                 // 端口号
  uint8_t pin;                  // 引脚号
  volatile uint32_t *pFuncReg;  // 这根脚的 IOCON 寄存器地址
} MyADC_ts;

/* src/my_adc.c:26~39 */
MyADC_ts leftAdcInst  = { .ch = 2, .port = LB_ADC_PORT, .pin = LB_ADC_PIN, .pFuncReg = &(LPC_IOCON->LB_ADC) };
MyADC_ts rightAdcInst = { .ch = 3, .port = RB_ADC_PORT, .pin = RB_ADC_PIN, .pFuncReg = &(LPC_IOCON->RB_ADC) };
MyADC_ts *pLeftAdcHandle  = &leftAdcInst;
MyADC_ts *pRightAdcHandle = &rightAdcInst;

宏展开（inc/my_board.h:262~267）：LB_ADC_PORT → 0，LB_ADC_PIN → 13，LB_ADC → TDO_PIO0_13，所以 &(LPC_IOCON->LB_ADC) 就是 PIO0_13 那个 IOCON 寄存器的地址 0x4004 4034。

这样写的好处：MyADC_Init(p) 和 MyADC_GetValue(p, &val) 只写一份，传左键的“把手”（handle）就操作左键，传右键的就操作右键。换板子时只改这两个结构体。

ADC 一句话来龙去脉
Device_Init() 最后调 MyADC_Init() 左右各一次：第一次调用时给 ADC 通电、开时钟、设 3 MHz（只做一次），每次都把自己那根脚改成“无上拉、模拟、AD 功能”。之后每 1 ms，按键扫描 LR_GetState() 依次读左、右：先读一次清旧标志、选通道、开始；芯片花 3.67 µs 转换；程序每 2 µs 看一次完成标志；取出 10 位结果交给按键算法。不用中断，休眠也不关。

左、右各读一次约 10 µs，只占 1 ms 的 1%。

6/7📖 手册导读：第 19 章 ADC（p.383~388，全部读完）

📖 p.383 · 19.2 Basic configuration：ADC 的“七步”原文。
📖 p.383 · 19.3 Features：10 位、8 路、0~3.6 V（不能超过 VDD）、最快 2.44 µs、可以连续扫描（burst）、可以用定时器触发。
📖 p.383 · 19.4 Table 350 Pin description：注意最后一行 VDD 就是参考电压 VREF。
问题 1：“10-bit conversion time ≥ 2.44 µs” 是怎么算出来的？这个项目实际是多少？ADC 时钟最高 4.5 MHz，一次 11 个时钟：11 ÷ 4.5 MHz ≈ 2.44 µs。这个项目设的是 3 MHz：11 ÷ 3 MHz ≈ 3.67 µs。
问题 2：为什么说 ADC 的读数是“相对于 VDD 的比例”？Table 350：VDD 就是 VREF（参考电压）。Table 355 说结果是“引脚电压 ÷ VREF”的二进制小数。所以如果 VDD 从 3.3 V 变成 3.2 V，同一个引脚电压读出来的数会变大。好在这个项目只关心“按下深度的相对变化”，而且有基线自动校准（第 14 课），影响不大。
📖 p.384 · Table 351 寄存器总览：CR、GDR、INTEN、DR0~DR7、STAT。
📖 p.385~386 · Table 352 CR：精读。SEL、CLKDIV、BURST、CLKS、START、EDGE 每个字段都读一遍。
问题 3：软件模式下，SEL 能同时选两路吗？不能。SEL 的说明：“In software-controlled mode (BURST = 0), only one of these bits should be 1.” 所以代码每次先选一路，读完再取消（my_adc.c:97、117）。BURST = 1 的硬件扫描模式才能同时选多路。
问题 4：START 写 1 是什么意思？写 2~7 呢？1 = 马上开始转换（Start conversion now）。2~7 = 等某个定时器的捕获或匹配信号到来时自动开始（19.6.1 硬件触发）。这个项目用 1。
📖 p.386 · Table 353 GDR：“全局”结果寄存器，存最近一次转换的结果，不管是哪一路。
📖 p.387~388 · Table 354 INTEN、Table 355 DR0~DR7、Table 356 STAT：精读 Table 355。
问题 5：GDR 和 DRn 有什么区别？这个项目用哪个？GDR 只存最近一次（哪一路都有可能），DRn 每一路各存一份。项目用 DR[ch]，读左键就看 DR2，不会和右键混。
问题 6：结果为什么要右移 6 位？Table 355：结果 V_VREF 在 bit15:6，bit5:0 是保留位。所以 (DR[ch] >> 6) & 0x3FF：先右移 6 位让结果落到最低位，再用 0x3FF（10 个 1）只留 10 位。
📖 p.388 · 19.6 Operation：硬件触发、中断、19.6.3 精度和数字接收器。
问题 7：19.6.3 为什么建议在 IOCON 里把引脚选成 ADC 功能？选成 ADC 功能（并设成模拟模式）会断开引脚的“数字接收器”，测量更准。这就是 MyADC_Init() 里要清 ADMODE、设 FUNC = 2 的原因（也见 p.82 7.3.7）。
📖 数据手册 p.38 · Table 6 ADC static characteristics：精度指标。
问题 8：ADC 的绝对误差最大是多少？对这个项目意味着什么？ET 最大 ±4 LSB，也就是读数可能偏差 ±4（约 ±13 mV）。按到底和松开差了约 500，±4 的误差很小；算法里还有滤波和基线校准。另外 Table 6 说输入电压范围 0 ~ VDD，模拟输入不能超过 VDD。

7/7容易出错、你能改什么、T1A

ADC 时钟设太快超过 4.5 MHz，结果不准（Table 352 CLKDIV）。48 MHz 至少要除以 11。
引脚没切成模拟模式 / 没关上拉读数偏、跳。19.6.3 和 7.3.7。
软件模式同时选了两路只能选一路，读完要取消。
没清旧 DONE可能马上读到上一次的结果。
BURST = 1 时 START 不是 0Table 352：“START bits must be 000 when BURST = 1 or conversions will not start.”
超时处理20 µs 没转完，LR_GetState() 直接返回 0，这一毫秒左右键都算松开 ⚠️（正常不会发生）。

你能改什么

  • 多采几次取平均：在 MyADC_GetValue() 外面连读 4 次求平均，噪声更小，但每次多花约 15 µs。
  • 改用 burst 模式：SEL 同时选 AD2、AD3，BURST = 1，硬件自动轮流转换，程序直接读 DR2、DR3，不用等。
  • 休眠时关 ADC 省电：在挂起流程里调用现成的 MyADC_HwDeinit()（my_adc.c:59，目前没人调用），唤醒后再初始化。

T1A 上

T1A 用霍尔芯片通过 SPI 读左右键，不再用 ADC；PIO0_13/14 改去控制线圈（03_T1A适配清单.md）。MyADC_Init() 和 IR_EN、LB_ADC、RB_ADC 的初始化都要去掉。但这一课学的“七步 + 读手册”的方法，下一课马上会用在定时器上。

小测验

这一课你只需要记住：ADC 像一把 1024 格的尺子，用“猜数字”的方法 11 个时钟量完一次。用它要：通电、开时钟、引脚设成模拟、设时钟 ≤ 4.5 MHz；每次读：选一路 → 开始 → 等 DONE → 取 bit15:6。这个项目每 1 ms 读左右各一次，结果交给按键算法。

ADC模数转换器：电压 → 数字
分辨率 / LSB一格多大：3.3 V / 1024 ≈ 3.2 mV；“1 LSB”就是一格
参考电压 VREF尺子的满量程，这里就是 VDD
逐次逼近（SAR）每次猜中间、一次排除一半的量法
通道ADC 的一路输入（AD0~AD7）
