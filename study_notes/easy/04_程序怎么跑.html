程序怎么跑

插上 USB 线那一刻起，芯片里发生了什么？这一课从通电讲到主循环，再讲清楚中断（门铃）到底是怎么打断程序、又怎么回来的。学完你就能回答：一行代码，在什么时候、被谁执行。

1/5从通电到 main()

你写的程序不是芯片通电后第一个运行的。在它前面还有两个“门卫”。点“下一步”看一遍：

动手 · 点“下一步”，跟着芯片开机
Bootloader（引导程序）：开机先运行的一小段程序，决定“跳去运行正式程序”还是“留下来接收新固件”。这个项目有两个：芯片出厂自带的（在 ROM 里，改不了），和公司自己写的（在 Flash 最前面 16 KB）。
向量表：程序最开头的一张“电话簿”，每一行写着一个地址：开机从哪里开始、每种中断该去找哪个函数。CPU 遇到中断时就来这里查号码。
栈：RAM 里的一块“临时记事区”（这个项目 512 字节）。函数调用、中断发生时，CPU 把“我刚才做到哪了”记在这里，回来时再取出来。

    3/5转圈干活：Device_Active()

    src/device.c:493。while(1) 就是“永远重复”，括号里的条件 1 永远成立，所以永远不会出来。每一圈做这些事：

    while (1)
{
    Device_Scan();        // ① 看一眼：读传感器；每 1 ms 扫一次按键和滚轮
    Device_Pack();        // ② 有变化就拼成报文
    Device_Report();      // ③ 把报文放进 USB 的 EP1
    wwdt_feed();          // ④ 喂看门狗
    PC_Communicate();     // ⑤ GUI 发来命令了吗
    Suspend_Check();      // ⑥ 电脑休眠了吗
    Ele_PollingTask();    // ⑦ 线圈的定时和保护
    Task_ParamGuard();    // ⑧ 参数要不要存进 EEPROM
    MyDebug_Task();       // 调试用，现在是空的
    MyADC_Poll_Test();    // 测试用，内容被 #if 0 关掉了
}

    每一项都是“看一眼，有事就做，没事马上走”，不会停下来等。所以一圈很快，远远不到 1 ms。主循环不能有“死等”，否则别的事都会被耽误。

    4/5门铃响了：中断到底怎么发生

    中断最神奇的地方是：主循环正在做任何事，都可以被打断，处理完又一点不差地回到原来那一行接着做，主循环自己完全感觉不到。这是怎么做到的？以 1 ms 定时器为例，点“下一步”：

    📖 用户手册 UM10462 · 第 24 章 · 24.3.3.6.1 Exception entry · 第 448~449 页 · Fig 81
    When the processor takes an exception ... the processor pushes information onto the current stack. This operation is referred to as stacking and the structure of eight data words is referred as a stack frame. ... The processor performs a vector fetch that reads the exception handler start address from the vector table.
    进中断时，CPU 自动把 8 个数（R0~R3、R12、LR、PC、xPSR）压进栈，这叫“压栈”；然后去向量表查中断函数的地址。这些都是硬件自动做的，不用写代码。

    5/5中断的三道闸门、优先级、怎么传话

    三道闸门：三个都开，门铃才会响

    闸门在哪这个项目里手册
    ① 外设自己愿意举手外设的寄存器定时器 MCR = 3；USB INTEN各外设章节（Table 303、Table 223）
    ② NVIC 允许这一路NVIC 的 ISERNVIC_EnableIRQ(...)第 6 章 Table 61，第 71 页
    ③ 总开关没关CPU 的 PRIMASK平时开着；写 EEPROM 时 __disable_irq() 关掉所有中断（src/IAP_CMD.c:47，1-6 课）第 24 章

    优先级：两个门铃同时响听谁的

    数字越小越优先（0 最高，3 最低，第 6 章 Table 71：“0 = highest priority. 3 = lowest priority.”）。这个项目里定时器是 0，USB 是 1。所以 USB 中断处理到一半时，定时器还能插进来，处理完再回到 USB；反过来不行。

    小测验

    这一课你只需要记住：通电后先跑两个 Bootloader，再从向量表找到程序入口，C 库把变量准备好，才进 main()。main() 先准备一次（Device_Init），再永远转圈（Device_Active）。中断随时插队：硬件自动保存现场、查向量表、执行中断函数、恢复现场。中断里只做小事，靠全局变量通知主循环去干活。

    本课新词

    Bootloader开机先跑的引导程序，决定运行正式程序还是升级
    向量表程序开头的电话簿：开机入口、每种中断的函数地址
    栈RAM 里的临时记事区，记“做到哪了”
    中断服务函数门铃响时被执行的函数，名字固定（如 TIMER16_0_IRQHandler）
    优先级门铃同时响时先听谁的，数字小的优先
    全局变量 / volatile所有函数都能看到的变量 / 告诉编译器“每次都重新读”
