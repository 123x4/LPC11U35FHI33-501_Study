单片机是什么

这一课先看芯片里装了什么，然后学一个以后每天都用的套路：芯片里的任何工具，都按同样的七步来用。后面讲 ADC、定时器、SPI、USB，全都会按这七步从头讲到尾。

先点中间的 CPU。
外设：芯片里除了 CPU 和存储器之外的那些“工具”，比如 GPIO、ADC、定时器、SPI、USB。它们是专门的硬件电路，设置好以后自己干活，CPU 不用一直盯着。

2/4每个开关都有门牌号

上一课说寄存器是一排开关。芯片里有几百排这样的开关，每一排都有一个地址（门牌号）。程序往某个地址写一个数，就是去拨那一排开关。

代码里写的 LPC_ADC->CR，是芯片厂商给地址 0x4001C000 起的名字（定义在 inc/LPC11Uxx.h）。你写名字，编译器替你换成地址。

3/4用任何外设都是这七步

把外设想成一台新买的电器。不管是电饭煲还是洗衣机，用法都差不多：

中断标志：外设想叫 CPU 的时候，会把自己的一个开关置 1，这个开关就是“标志”。CPU 去处理（进中断函数）之后，必须把它清回 0，否则 CPU 一出来就看到它还是 1，又被叫回去，程序就卡在中断里出不来了。就像闹钟响了要按掉。
轮询：不用中断，程序自己隔一会儿去看一眼“好了没”。等的时间很短时（比如 ADC 只要 4 微秒），轮询比中断简单。

七步只是“清单”，真正的来龙去脉要按时间看

七步告诉你“要做哪些事”，但没告诉你什么时候做、谁来做、做完之后它怎么一直工作下去。所以每个模块都画成下面这种生命周期图：

  • 从左到右是时间：开机准备（只做一次）→ 平时工作（反复）→ 中断（有的话）→ 停止或出错。
  • 从上到下是谁在做：🟦 芯片自己 / ⬜ 现成的例程代码 / 🟩 这个项目的代码（你负责）。
  • 每个方块上的数字是真实的执行顺序，右上角小标签是它属于七步里的哪一步。点“下一步”按顺序走一遍，或者直接点方块。

4/4以后每个模块课都这样讲

模块课的固定结构（以第 7 课 ADC 为例）：

  1. 它是干什么的：原理，用图和动手演示
  2. 生命周期图：开机准备 → 平时工作 → 中断 → 停止/出错，每一步的代码、文件行号、谁负责（就是上面这种图，会画得更细）
  3. 七步核对：①~⑦ 哪些有、哪些不需要、为什么
  4. 标志和残留：哪些标志要清、谁清、在哪清，例程已经清了的明确标出
  5. 容易出错的地方：比如忘了通电、引脚功能选错、标志没清
  6. 你能改什么：要改它时改哪几行，会影响什么
  7. T1A 上的变化

小测验

这一课你只需要记住：单片机 = CPU + 存储器 + 一堆外设。用任何外设都是七步：通电 → 开时钟 → 解锁 → 接线 → 调设置 → 要不要中断 → 使用（用了中断就要清标志）。不是每个外设都需要全部七步。

本课新词

外设芯片里的专用工具电路（GPIO、ADC、定时器、SPI、USB…）
地址每排开关（寄存器）的门牌号
时钟让电路一步步工作的节拍。这颗芯片是 48 MHz，每秒 4800 万拍
中断 / 标志外设叫 CPU 的方式 / 外设用来“举手”的那个开关，处理完要清掉
轮询不用中断，程序自己去看“好了没”
