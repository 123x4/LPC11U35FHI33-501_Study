常问的 6 个问题

GUI 发来的包落在哪？0x2000_4500 起 64 字节（EP4 OUT buf0）。表格那一格在 0x2000_4040。
鼠标回 GUI 的包写在哪？0x2000_4480 起（EP3 IN buf0），表格那一格在 0x2000_4038。
怎么知道收到了 / 能发了？看表格那一格的 bit31（A）：A = 0 就是“收到了”或“上一包已发走”。函数 nsAPI_USB_EP_Status（usbhw.c:1429）。
收到了几个字节？64 − 表格里剩下的 NBytes（bit25~16）。usbhw.c:1183。
端点地址 → 表格第几格？(端点号 × 2 + 方向) × 2，方向 OUT=0、IN=1；每格 4 字节。例：0x04 → (4×2+0)×2 = 16 → 0x2000_4000 + 16×4 = 0x2000_4040。
表格里的 Offset 怎么变回地址？缓冲区地址 = 0x2000_0000 + Offset × 64。例：0x0114 × 64 = 0x4500 → 0x2000_4500。

位名字意思（手册 Table 227）
31A Active1 = 这块缓冲区交给硬件了：OUT 端点可以接收，IN 端点等着被电脑取走。硬件收完 / 发完自动清 0。软件只能写 1
30D Disabled1 = 端点关闭，电脑来访问时硬件不理。初始化时非 0 端点都置 1（usbhw.c:258），配置完成后 nsAPI_USB_EnableEP 清 0（:900）
29S Stall1 = 回电脑“出错 / 不支持”
28TR Toggle Reset写 1 时把数据翻转位设成 TV 的值（USB 的 DATA0 / DATA1 交替）
27RF / TV翻转值 / 速率反馈模式
26T Type0 = 批量或中断端点（本项目全是 0）；1 = 同步端点
25~16NBytesOUT：最多能收几字节（填 64）；IN：要发几字节。硬件每传一个包就减掉包长
15~0Address Offset缓冲区地址的 bit21~6（地址 ÷ 64）。高位在 DATABUFSTART 寄存器里，所以缓冲区必须 64 字节对齐
③ 一个包怎么进来、怎么出去（软件拷贝 + 硬件搬运）
