1/7🧭 本质：函数是搬运工，全局变量是黑板

一次点击，就是一个“按下了”的消息，被一串函数从一块全局变量搬到下一块，最后搬进 USB 的格子里。

主循环里的这些函数几乎不靠参数传话，而是靠全局变量：前一个函数把结果写到某个全局变量（黑板）上，后一个函数在下一刻去读。所以你读某个函数时觉得“看不懂”，往往是因为不知道它读的那块黑板是谁、在什么时候写上去的。下面这条接力链，点任意一块，跳到它的说明：

2/7读全局变量的 5 个要点

这不是 C 语法课，是“在一个嵌入式工程里，怎么读懂全局变量”：

  1. 1
    全局 = RAM 里一个固定地址，开机到断电一直在。地址在 List/Sample.map 里能查到，比如 wheel_button_status 在 0x1000 03B8。局部变量只在函数运行时临时放在栈上，函数一返回就没了；同一个函数下次再进来，局部变量是新的。
  2. 2
    “定义”只有一处，“extern 声明”可以有很多处。定义（UINT32 wheel_button_status;，device.c:51）才真正占内存；别的文件写 extern UINT32 wheel_button_status;（device.h:684）只是说“这个变量在别处，借我用”。找一个全局变量，先找它的定义在哪个文件，那个文件通常就是它的“主人”。
  3. 3
    static 有两种意思。写在函数外：这个变量只有本文件能用（比如 mySysTickMs，别的文件要用只能调 MyTick_GetTickMs()）。写在函数里：它不是临时的，会记住上一次的值（比如 Custom_HandleKey() 里的 last_button_wheel_status，靠它才知道“哪一位变了”）。
  4. 4
    结构体 = 把相关的变量打包放一起。buttonScan_stru 里打包了“当前看到的”“已经确认的”“倒计时”“有没有变”4 样东西，都是按键扫描要用的。用 . 访问成员（buttonScan_stru.scan_result_pre），拿着指针时用 ->（report_pointer->mouse_report）。
  5. 5
    对每个全局变量，问三个问题：谁写？谁读？什么时候？下面第 4 节的图鉴，每个变量都回答了这三个问题。

    6/7💡 想法上

    1. 读一个函数之前，先列出它碰到的全局变量
    一个函数看不懂，十有八九不是语法问题，而是不知道它读的全局变量里此刻装着什么。以后读任何函数，先扫一遍，把函数体里所有“不是参数、也不是在函数里定义的”名字圈出来，逐个查：定义在哪、谁写、什么时候写。查完再读函数，会顺很多。这一页的“全局变量图鉴”就是这样做出来的。
    2. 同名不等于同一个东西
    device.c:73 有一个全局数组 mouse_temp[13]，custom.c 的 Custom_HandleKey() 里也有一个局部数组 mouse_temp[8]。在 Custom_HandleKey() 里写 mouse_temp，指的是自己的局部那个，和 device.c 的全局那个毫无关系。读代码时看到一个名字，先确认它是“这个函数自己的”还是“外面的”。
    3. 我之前说错了一处，这里更正
    在“app 文件夹四份代码”那页，我写过“Ele_*Process() 只是登记要震，真正的脉冲在 Ele_PollingTask() 里输出”。这是错的。本项目打开了 BRAKE_FUNC_ENABLE，Ele_LeftKeyPressProcess() 当场就把 PIO0_4 拉高、用 CT16B1_DelayUs() 忙等设定的时长、再拉低（第 3 节第 10 步）；Ele_PollingTask() 只管之后 8 ms 的“震后消抖”。那一页已经改了。这也是第 1 条的反面例子：我当时没去读 Ele_LeftKeyPressProcess() 的函数体，凭函数名猜了它的行为。

    记住这条接力链：红外电压 → LPC_ADC->DR[2] → hall_spi_rx → 滤波 + 状态机 → gbKeyState[1] → buttonScan_stru.scan_result_pre 第 0 位（同时线圈震一下）→ wheel_button_status + deviceEvent → 查 gloabSetting.settingMode.key_function[0] → 局部 manual_mouseReport → mouseReport_back、report_data → USB RAM 0x2000 4280 → 电脑。

    本页新词

    全局变量 / 局部变量一直在固定地址 / 函数运行时临时在栈上
    定义 / extern 声明真正分配内存（只有一处）/ 告诉编译器“在别处，借用”
    static 局部变量写在函数里，但会一直存在、记住上次的值
    栈RAM 里给局部变量临时用的一块，函数返回就收回
    黑板式通信函数之间不传参数，而是写读同一个全局变量来传话
