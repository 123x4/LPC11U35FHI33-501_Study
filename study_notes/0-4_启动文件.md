# 0-4 启动文件：从 Reset_Handler 到 main()

> 📍 **位置**：上电 → ROM → 公司 Bootloader → `boot_jump()` 跳到 0x9A1C → **`Reset_Handler` → `__main` → `main()`（本课）** → `Device_Init()`（第 1 部分）
> 📄 **代码**：`src/startup_LPC11Uxx.s`、`src/Main.c`
> 🔍 **核对用的编译产物**：`List/Sample.map`、`output/Sample.axf`（反汇编）、`output/Sample.hex`
> 📖 **手册**：UM p30 Table（MAINCLKSEL）、p394~395（CRP）、p434（栈）、p446~447（向量表）

---

## 全程一览

```
boot_jump() 跳到 0x0000 9A1C
   │
   ▼
Reset_Handler（启动文件，2 条指令）
   │  跳到 __main
   ▼
__main（Keil C 库，0x40C0）
   ├─ ① 再设一次栈指针 SP = 0x1000 1BD8
   ├─ ② __scatterload：按 Region$$Table 初始化 RAM
   │      第 0 项：把 Flash 0xF100 的变量初值解压到 RAM 0x1000 0100（856 字节）
   │      第 1 项：把 RAM 0x1000 0458 起的 6016 字节清零
   └─ ③ 跳到 main（0x40D8）
   ▼
main()：Device_Init(); Device_Active();
```

## 第 1 部分：逐段读启动文件 `src/startup_LPC11Uxx.s`

### ① 栈和堆（第 31~47 行）

```asm
Stack_Size      EQU     0x00000200                 ; 栈 512 字节
                AREA    STACK, NOINIT, READWRITE, ALIGN=3
Stack_Mem       SPACE   Stack_Size
__initial_sp                                       ; 栈顶，map 第 1449 行：0x1000 1BD8

Heap_Size       EQU     0x00000000                 ; 堆 0 字节
```

- 栈：0-3 课 Q5 已经讲过，map 第 829 行：`STACK 0x100019d8 Section 512`。
- **堆为 0**：堆是给 `malloc()` 用的。这个项目不用 C 库的 `malloc()`（`Led_Effect_Gruop_Code/ram_malloc.c` 是项目自己写的内存分配，用的是一个全局数组），所以不需要堆。map 第 406 行：`Removing startup_lpc11uxx.o(HEAP), (0 bytes)`，链接器直接把它删了。

### ② `PRESERVE8` / `THUMB`（第 50~51 行）

- `PRESERVE8`：告诉链接器，这个文件里的代码保持栈 8 字节对齐（ARM 的函数调用约定要求）。
- `THUMB`：下面的指令用 Thumb 指令集。Cortex-M0 **只能**执行 Thumb 指令，这也是向量表里地址最低位都是 1 的原因。

### ③ 向量表（第 56~111 行）

就是向量表那一课讲的 48 项 `DCD`。`AREA RESET` 这个段名很关键：`output/Sample.sct` 里写着 `*.o (RESET, +First)`，要求链接器把它放在 app 的**最前面**。map 第 600 行附近可以看到：`RESET 0x00004000 Section 192`，正好 192 字节 = 48 项 × 4。

### ④ CRP 代码读保护（第 113~120 行）

```asm
                IF      :LNOT::DEF:NO_CRP
                AREA    |.ARM.__at_0x02FC|, CODE, READONLY
                DCD     0xFFFFFFFF                 ; 放在 Flash 地址 0x2FC
                ENDIF
```

📖 **UM p394~395**：ROM 程序会读 Flash **0x2FC** 处的一个字，决定芯片的保护级别。0xFFFFFFFF 表示**不保护**，可以用 ISP 读出、改写 Flash。注释里列出的其他值（`0x12345678` = CRP1 等）会禁止读出，`0x4E697370` = NO ISP 甚至会**关掉 ISP**。这些值一旦写错，可能再也没法用 ISP 救砖，所以注释里写着 `ARE YOU SURE?`。

注意 0x2FC 在 Bootloader 的区域里（小于 0x4000），ROM 实际检查的是 **Bootloader 那份**。app 的 hex 里虽然也带着这一条记录（map 第 593 行：`.ARM.__at_0x02FC 0x000002fc`），但 Fw Update 升级时会不会写它，取决于 Bootloader，**【待确认】**。

### ⑤ Reset_Handler（第 127~135 行）—— 本课的起点

```asm
Reset_Handler   PROC
                EXPORT  Reset_Handler             [WEAK]
;               IMPORT  SystemInit                ; ← 被注释掉了
                IMPORT  __main
;               LDR     R0, =SystemInit
;               BLX     R0
                LDR     R0, =__main
                BX      R0
                ENDP
```

反汇编 `output/Sample.axf` 的实际结果：

```
00009a1c <Reset_Handler>:
    9a1c: 4804   ldr r0, [pc, #0x10]   ; 从 0x9A30 读出常量 0x000040C1
    9a1e: 4700   bx  r0                ; 跳到 0x40C0（__main），最低位 1 = Thumb
```

**只有两条指令**：读出 `__main` 的地址，跳过去。

- 很多工程会在这里先调用 `SystemInit()` 配置时钟。这个项目把它注释掉了，时钟改在 `Device_Init()` 的第 2 行 `InitSystemOSC()` 里配置（1-2 课）。
- `Reset_Handler` 放在 0x9A1C，不在 app 开头。没关系，CPU 是通过向量表第 1 项找到它的，它放在哪里都行。

### ⑥ 默认中断处理函数（第 138~223 行）

```asm
NMI_Handler     PROC
                EXPORT  NMI_Handler               [WEAK]
                B       .                         ; 跳到自己：死循环
                ENDP
...
Default_Handler PROC
                EXPORT  TIMER16_0_IRQHandler      [WEAK]
                ...（26 个中断名）
TIMER16_0_IRQHandler
...
                B       .
```

两个关键点：

- **`B .`**：“跳到本条指令自己”，也就是原地死循环。
- **`[WEAK]`（弱定义）**：如果哪个 C 文件里写了同名函数（比如 `src/Timer.c` 里的 `TIMER16_0_IRQHandler`），链接器就用 C 文件里的那个；没写的，就用这里的死循环。

所以向量表那一课里，`ADC_IRQHandler`、`BOD_IRQHandler` 等项都指向同一个地址 **0x9A2D**，这就是 `Default_Handler` 的死循环。

**这意味着**：如果某个中断在 NVIC 里被使能了，却忘了写处理函数，中断一来 CPU 就会卡在这个死循环里，主循环不再运行，鼠标“死掉”，直到看门狗把芯片复位（看门狗是 1-1 课的内容）。`HardFault_Handler` 也是死循环，程序出现严重错误时同样会卡在这里。

### ⑦ 栈和堆的导出（第 229~251 行）

```asm
                IF      :DEF:__MICROLIB
                EXPORT  __initial_sp
                EXPORT  __heap_base
                EXPORT  __heap_limit
                ELSE
                ...（__user_initial_stackheap）
                ENDIF
```

这个工程在 Keil 里勾选了 **Use MicroLIB**（`Sample.uvproj` 第 232 行 `<useUlib>1</useUlib>`），编译时会自动定义 `__MICROLIB`，所以走上半段：直接把栈顶、堆的起止地址告诉 C 库。`ELSE` 部分不会被编译。MicroLIB 是 Keil 为小芯片准备的精简 C 库，体积小，map 文件里的 `mc_p.l` 就是它。

## 第 2 部分：`__main` 做了什么（C 库代码，不在我们的源文件里）

`__main` 由 C 库提供，在 0x40C0，紧接在向量表后面。反汇编 `output/Sample.axf`：

```
000040c0 <__main>:
    40c0: 4804   ldr r0, [pc, #0x10]      ; r0 = 0x1000 1BD8
    40c2: 4685   mov sp, r0               ; ① 再设一次栈指针
000040c4 <_main_scatterload>:
    40c4: ...    bl  __scatterload        ; ② 初始化 RAM
000040c8 <_main_init>:
    40c8: 4800   ldr r0, [pc, #0x0]       ; r0 = 0x000040D9
    40ca: 4700   bx  r0                   ; ③ 跳到 main（0x40D8）
```

### ① 再设一次栈指针

和 Bootloader 在 `boot_jump()` 里设的值一样，都是 0x1000 1BD8。如果芯片是从向量表正常启动的，硬件也会设同样的值。这里再设一次，保证无论从哪里进来，栈都是对的。

### ② `__scatterload`：初始化 RAM 里的全局变量

**为什么必须有这一步？** C 语言规定：

- 写了初值的全局变量，比如 `int a = 5;`，程序开始时 `a` 就必须是 5；
- 没写初值的全局变量，比如 `int b;`，程序开始时必须是 0。

可是 RAM 断电就丢，复位后里面是随机值。所以在进入 `main()` 之前，**必须有人把初值写进 RAM、把该清零的清零**，这个人就是 `__scatterload`。

它照着 Flash 0xC4F4 处的一张表 `Region$$Table` 来做（map 第 1308 行），表里每项 16 字节：源地址、目标地址、长度、处理函数。我从 `output/Sample.hex` 里把这张表读了出来：

| 项 | 源（Flash） | 目标（RAM） | 长度 | 处理函数 | 做什么 |
|---|---|---|---|---|---|
| 0 | 0x0000 F100 | 0x1000 0100 | 856 字节 | `__decompress`（0xB9CF） | 把**有初值的变量**（RW 区，`.data`）的初值解压到 RAM |
| 1 | 0x0000 F28C | 0x1000 0458 | 6016 字节 | `__scatterload_zeroinit`（0xBA7D） | 把**没有初值的变量**（ZI 区，`.bss`）和**栈**全部清零 |

**两个细节**：

- 第 0 项的初值在 Flash 里是**压缩**存放的：856 字节压成了 0x18C = 396 字节（map 第 1576 行 `COMPRESSED[0x0000018c]`）。所以 app 的 Flash 用量是：代码和常量 0x4000~0xF0FF，加上压缩的初值 0xF100~0xF28B，正好对上 `Sample.hex` 结束于 0xF28B。
- 第 1 项清零的范围是 0x1000 0458 + 6016 = **0x1000 1BD8**，正好到栈顶，栈也被清零了。

**拿项目里的真实变量举例**：
- `src/my_electromagnet.c` 里的 `leftEle` 写了初值（`.pressVibrateDurationUs = 100` 等），属于 RW（map 第 1367 行：`leftEle 0x10000206 … my_electromagnet.o(.data)`），由第 0 项从 Flash 解压到 RAM；
- `src/pc_communicate.c` 里的 `UINT8 receive_buff[TRANSFER_LENGTH];` 没写初值，属于 ZI（地址 0x1000 1650，在 `pc_communicate.o(.bss)` 里），由第 1 项清零。
- ⚠️ 一个容易想错的地方：`src/my_misc.c` 里的 `uint8_t gbKeyState[ANA_TOTAL_COUNT] = {0};` 虽然初值是 0，但因为**显式写了初值**，这个编译器（ARM Compiler 5）仍然把它放在 RW 区（map 第 1369 行：`gbKeyState 0x1000030c … my_misc.o(.data)`）。结果一样都是 0，只是它的初值要占 Flash 空间，由第 0 项复制过来。

### ③ 跳到 `main()`

`main` 在 0x40D8（map 第 854 行），`_main_init` 读出常量 0x40D9，用 `bx` 跳过去。

## 第 3 部分：`main()`（`src/Main.c`）

```c
int main (void)
{
    Device_Init();      // 初始化（第 1 部分逐行讲）
    Device_Active();    // 主循环 while(1)，永远不返回（第 2 部分逐行讲）
    return 0;           // 永远执行不到
}
```

反汇编（0x40D8）：`push` → `bl Device_Init` → `bl Device_Active` → `movs r0, #0` → `pop`，和源码一一对应。

## 进入 main() 这一刻，芯片处于什么状态

后面逐行读 `Device_Init()` 时，要以这张表为起点：

| 项目 | 状态 | 依据 |
|---|---|---|
| 主时钟 | **IRC 内部振荡器 12MHz**（还没切到 48MHz） | 📖 UM p30：MAINCLKSEL 复位值 0 = IRC。ROM、Bootloader、启动文件都没有改过时钟 |
| 中断向量表 | 从 RAM 0x1000 0000 读（app 的副本） | Bootloader 设了 SYSMEMREMAP = 1 |
| 栈指针 SP | 0x1000 1BD8 | `__main` 第一条指令 |
| 全局变量 | 有初值的已赋值，其他的已清零 | `__scatterload` |
| 中断总开关 | 打开 | Bootloader `boot_jump()` 里调用过 `__enable_irq()` |
| 各个外设中断 | 全部未使能 | 还没有任何代码调用 `NVIC_EnableIRQ()` |
| 外设、引脚 | 复位后的默认状态 | Bootloader 没来得及初始化任何外设就跳过来了 |

## 补充问答

**Q1：堆到底是什么？**
程序里的变量按“什么时候存在”分三种：
| 种类 | 什么时候存在 | 放在哪里 | 谁管理 |
|---|---|---|---|
| 全局变量（写在函数外） | 程序开始到断电一直存在 | 固定地址，map 里能查到 | 编译器、链接器 |
| 局部变量（写在函数里） | 函数调用时才有，返回就没了 | **栈** | CPU 自动 |
| 动态申请的内存 | 运行中用 `malloc()` 借、`free()` 还 | **堆** | `malloc()` / `free()` |

启动文件里 `Stack_Size`、`Heap_Size` 两行，就是事先在 RAM 里给栈和堆各圈出一块地。这个项目没有调用 `malloc()`，所以 `Heap_Size = 0`。
`Led_Effect_Gruop_Code/ram_malloc.c` 名字里有 malloc，但它不是堆：它是一个 256 字节的**全局数组** `malloc_ram`（map 第 1448 行，地址固定），项目自己写函数从里面分块。

**Q2：把 `Heap_Size` 改成 0x400（1024 字节）放得下吗？**
map 第 1576 行：app 的 RAM 上限 `Max: 0x1e60` = 7776 字节，已用 `Size: 0x1ad8` = 6872 字节，只剩 904 字节。堆要 1024 字节，超出 120 字节，链接时就会报错，程序编译不出来。

**Q3：map 文件的两种行怎么看？**
- 符号行（搜变量名或函数名）：`leftEle  0x10000206  Data  29  my_electromagnet.o(.data)` 依次是 名字、地址、类型、大小、来自哪个文件（哪个段）。段名 `.data` = 有初值（RW 区），`.bss` = 没有初值（ZI 区）。
- 区域行（搜 `Execution Region`）：`RW_IRAM1 (Exec base: 0x10000100, … Size: 0x00001ad8, Max: 0x00001e60 …)` 依次是 起始地址、已用多少、最多能用多少。
