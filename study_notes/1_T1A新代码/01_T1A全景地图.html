T1A 霍尔触觉鼠标：全景地图

这一页只回答三件事：板子上有哪几块东西、各接在 MCU 哪只脚上？固件整体是什么结构？接下来按什么顺序学？细节都留给后面的课。

🧭 本质：一只鼠标 = 一颗 MCU（LPC11U35）+ 周围几块“外设电路”。MCU 通过引脚和它们说话：读按键、读两颗霍尔芯片、读光学传感器、驱动两个线圈、通过 USB 把结果发给电脑。

固件也只有三部分：开机初始化一遍（把每块电路设好）→ 一个永远在转的大循环（读、算、发）→ 几个中断（时间到了、USB 来数据了，硬件打断循环插一件急事）。后面每一课，都是在这张图上放大其中一块。

1. 这是一只什么鼠标（先看场景）

你按下左键：按键里的磁铁靠近霍尔芯片（感应磁场强弱的芯片，按 H5 即 GTRY154 设计），芯片读数变化 → MCU 每 1 ms 读一次，算出“按到了几成” → 判定为“按下” → 立刻让左键下面的线圈通电震一下，手指感觉到“咔”的一下（这就是“触觉”） → 同时把“左键按下”通过 USB 发给电脑。

所以和普通鼠标比，它的左右键没有机械开关，“咔哒”的手感是线圈震出来的。其余部分（侧键、中键、DPI 键、光学传感器、滚轮、USB）和普通鼠标一样。

4. 固件的骨架

main()（src/Main.c:13）只有两句：Device_Init() 和 Device_Active()。前者把每块电路设好，后者是永远不退出的大循环。

开机初始化 Device_Init()（device.c:415）

  1. 看门狗 wwdt_config · 419
  2. 系统时钟 12 MHz → 48 MHz InitSystemOSC · 420
  3. 引脚：按键输入、霍尔上电、线圈脚拉低 InitGPIO · 421
  4. 线圈：PWM 和波形定时器、升压 Ele_Init · 422
  5. USB 时钟 InitUSBOSC · 429
  6. 从 EEPROM 读手感和线圈参数 Param_Init · 433
  7. 霍尔用的 SPI1 InitSPI1Master · 441
  8. 1 ms 节拍定时器 InitCT16B0 · 447
  9. USB 初始化 nsAPI_USB_Init · 451
  10. GUI 通信缓冲区 三个 *_Pointer_Init · 453~455
  11. 等 0.5 秒 TimerDelayMsec(500) · 457
  12. 配置两颗霍尔芯片 HallSensor_INIT · 462
  13. 键位、配置档案 465~477
  14. 掉电复位 BODCTRL · 482
  15. 光学传感器 PAW3950_Init · 491

大循环 Device_Active()（device.c:496）

  1. 扫描：读传感器位移；每 1 ms 扫一次按键（含霍尔左右键和震动） Device_Scan · 512
  2. 组包 Device_Pack · 514
  3. 通过 USB 发给电脑 Device_Report · 516
  4. 喂看门狗 wwdt_feed · 518
  5. 处理 GUI 发来的命令 PC_Communicate · 520
  6. 电脑睡了就挂起 Suspend_Check · 522
  7. 线圈状态：震完 → 消抖 → 空闲 Ele_PollingTask · 525
  8. GUI 改了参数就存 EEPROM Task_ParamGuard · 527
  9. 调试（现在关着） MyDebug_Task · 529

主线上的三个中断

  1. 每 1 ms：计时、给按键扫描“发令” TIMER16_0 · Timer.c:65
  2. 震动时每 20 µs：改一次线圈力度 TIMER32_0 · my_waveform.c:87
  3. USB 有事：收发数据 USB_IRQHandler · usbhw.c:1333

按一下左键，走过哪些地方（第 2 课会逐站讲）

① 每 1 ms：Button_Scan() → LR_GetState() → hall_get_sample()：通过 SPI1 读两颗霍尔芯片（button.c:311、858）
↓
② 按键算法 ProcessRecvSampleRawData()：读数 → 滤波 → 段位 0~100 → 判断按下 / 松开（my_misc.c:418）
↓ 刚判定按下
③ Ele_LeftKeyPressProcess()（button.c:639 调用）：启动波形，CT32B1 在 PIO0_13 输出 200 kHz PWM，左线圈震一下
↓
④ Device_Pack() 组包 → Device_Report() 交给 USB → 电脑收到“左键按下”

6. 原理图和代码对不上、或要确认的地方

要问杰哥 / 上板确认
  1. 线圈升压使能：原理图上 7 V 升压芯片 ETA1628 的 EN 接的是电源开关来的 PWR_EN；代码用 HP_EN = PIO1_19 控制升压（my_board.h:365~367、my_electromagnet.c:97~98），而原理图上 PIO1_19（第 1 脚）没有接网络。可能板子改过，或者这段代码是沿用的。
  2. 滚轮编码器引脚：原理图是 PIO0_17 = SCROLL_EN（给编码器的灯供电）、PIO0_18 = SCROLL_UP、PIO0_19 = SCROLL_DOWN；代码写的是 ZA = PIO0_17、ZB = PIO0_18（my_board.h:356~359）。现在 ENABLE_WHEEL_SCAN = 0，滚轮功能关着，打开前要先对齐。
  3. 参数存 EEPROM 可能越界：参数结构 AllParam_ts 189 字节，从 0xF06 写到 0xFC2，超过代码注释和手册给的上限 0xFBF（最高 64 字节保留）；写入返回值没检查（my_protocol_mouse.c:138、214）。
  4. 充电芯片 BQ21128：原理图上用 I2C（PIO0_4 / 5）和 /CE（PIO0_1）连着，代码里 InitI2C() 被注释掉了（device.c:431），目前没有驱动它。
其他“还在做”的部分（GUI 下发的波形表还没接到线圈、MFG 命令只有定义）见 study_notes/待确认问题.md。

7. 学习路线：从哪里开始

建议：先读完这一页，下一课就讲“一次左键点击”的全程。理由：这只鼠标的核心就是“按下 → 震动 → 上报”，这条线穿过了霍尔、算法、线圈、USB 四块最重要的代码。先把这条线走通，后面每一课都是在这条线上放大一站，你始终知道自己学的东西在哪、干什么用。开机初始化放在后面，因为每一步初始化，只有在你知道那块电路平时怎么用之后才好懂。

  1. 全景地图（本页）
  2. 一次左键点击全程：只走主线，每站讲“它干什么”，不深挖
  3. 霍尔芯片（H5 / GTRY154）和 SPI1：（上）读一次：两颗芯片怎么串起来、怎么读；（下）① 开机准备 SPI1、② 开机准备霍尔芯片
  4. 按键算法：读数 → 段位 → 按下 / 松开（ADC 串讲第 5~10 关的讲法，换成霍尔的数）
  5. PWM：CT32B1 怎么在一只脚上输出 200 kHz、占空比可调的方波
  6. 波形：CT32B0 中断每 20 µs 改一次占空比，100 个点怎么在任意时长里放完
  7. 线圈状态机：什么时候震、震多久、震完怎么消抖
  8. USB 上报：组包、发包
  9. GUI 协议：GUI 怎么读写手感参数、波形表；参数怎么存 EEPROM
  10. 其余：侧键 / 中键 / DPI、光学传感器 PAW3950、开机初始化逐步、看门狗、挂起

每一课都按“问题 → 一句话规则 → 数字例子 → 自己算 → 代码”来，配随机练习题。芯片本身的基础（GPIO、定时器、SPI、USB、EEPROM……）在 2_基础课 里，用到时回看。

8. 练习：引脚和电路

先把“哪只脚接什么”记熟，后面读代码时看到 PIO0_21 就知道是霍尔的数据线。题目随机，可以一直做。

💡 想法上：读一块板子的固件，原理图和代码要一起看。代码只告诉你“软件以为”某只脚接了什么，原理图才告诉你它实际接了什么。这一页对照时就发现了两处对不上（升压使能、滚轮脚），只看代码是发现不了的。以后每学一块电路，都先在原理图上找到它，再去看代码。
