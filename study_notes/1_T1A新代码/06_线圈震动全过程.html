线圈震一下：从“判出按下”到手指感到“咔”

这只鼠标的左右键没有机械开关，手指感到的“咔哒”是旁边一个线圈通电半毫秒、把按键往上“踢”一下产生的。这一课从第 5 课的 Button_Scan() 发现“左键刚按下”开始，一路讲到线圈里的电流：谁下命令、电压从哪来、怎么用 PWM 控制力度、半毫秒里力度怎么按“波形”变化、震完之后为什么还要“冷静”十来毫秒。

🧭 本质（打个比方）：线圈像一面鼓，MCU 是鼓手。导通时间是“这一下敲多久”（默认 500 µs）；PWM 占空比是“每一瞬间用多大力”（0 ~ 100%）；波形表是“这一下里力度怎么变”（先轻后重再轻，像一个小山包）。敲完以后鼓面还在晃，旁边的霍尔芯片会被干扰，所以要等十来毫秒（消抖）再相信霍尔读数。

三个时间尺度，一层套一层，后面会逐层放大：

毫秒级：状态机按下 → 震动中（约 2 ms）→ 消抖（约 9 ms）→ 空闲。主循环里的 Ele_PollingTask() 管
20 µs 级：波形500 µs 的一次震动分成 25 段，每 20 µs 换一个力度。CT32B0 定时器中断管
5 µs 级：PWM每 5 µs 一个开关周期（200 kHz），“开”的比例就是力度。CT32B1 定时器硬件自己产生

1. 硬件：电从哪来、怎么开关

原理图上：7 V 升压芯片 ETA1628 产生线圈电源 H_VDD → 线圈 → MOS 管 MS3416K → 地。MCU 的 PWM 脚（左 PIO0_13、右 PIO0_14）接 MOS 管的栅极：脚为高，MOS 管导通，线圈有电流；脚为低，MOS 管断开。旁边的二极管 DS32W 在断开瞬间给线圈电流一条回路（续流），保护 MOS 管。点按钮看电流怎么走：

#define Ele_EnableBoost()   DrvGPIOOutput(HP_EN_PORT, HP_EN_PIN, 1)   // my_electromagnet.c:97，HP_EN = PIO1_19
void Ele_Init(void)                    // 416，开机时 Device_Init() 调（device.c:422）
{
  Ele_DisableBoost();                  // 441 先关升压
  MyWaveform_Init();                   // 442 配好 PWM（CT32B1）和波形定时器（CT32B0）

3. 放大到 20 µs：一次震动里力度怎么变

力度不是一下子开满，而是按波形表 wfCustomTbl[100]（my_electromagnet.c:312）变化：从 60% 慢慢升到 100%，再慢慢降回 60%，像一个小山包。导通时间由 GUI 的“按下振感强度”设定（默认 500 µs，最大 5000 µs）。拖动滑块看它被切成几段、每段用表里的哪个数：

MyWaveform_StartGenerate(CHANNEL_0, pLeftWf, wfPeriodUs, 1)          // my_waveform.c:155；左线圈用通道 0，右线圈通道 1
  periodUs    = wfPeriodUs，限制在 20 ~ 5000                            // 170~178
  updateTimes = periodUs / 20                                            // 179：要换几次力度（UPDATE_PERIOD_US = 20）
  inc         = (表长 100 << 15) / updateTimes                         // 195：每次在表里往前走多少格（放大 2¹⁵ 倍保留小数）
  acc         = inc >> 1                                              // 196：从“半步”开始，取每一段的中间
  MyWaveform_Start(): 先用 表[acc >> 15] 设占空比、开 PWM、定 20 µs 后的闹钟  // 278~291
TIMER32_0_IRQHandler(): 每 20 µs 闹一次                                  // 87~99
  MyWaveform_UpdateFromIsr(): acc += inc；idx = acc >> 15                // 237~238
    idx < 100 → MyPWM_SetDuty(表[idx])，闹钟再往后定 20 µs               // 239~243
    idx ≥ 100 → 走完一遍（cycles = 1）→ MyWaveform_Stop()：PWM 关，脚拉低  // 244~251

4. 放大到 5 µs：PWM 怎么做出“百分之几的力”

CT32B1 定时器的计数器 TC 从 0 数到 240 再回 0，每数一下 1/48 µs，所以一圈 240 ÷ 48 = 5 µs（200 kHz）。另有一个比较值 MR0（左）/ MR1（右）：TC 小于它时脚为低，大于等于它时脚为高。比较值越小，高电平越长，力越大。百分比到比较值的换算查表 Freq200kHzDuty[101]（my_pwm.c:19）。

寄存器写成意思（my_pwm.c:72~105）
IOCON PIO0_13 / PIO0_14FUNC 3脚接到 CT32B1_MAT0 / MAT1（定时器直接驱动脚）
SYSAHBCLKCTRL 第 10 位1给 CT32B1 时钟
PR0不分频，TC 每 1/48 µs 加 1
MR3240TC 到 240 清零 → 周期 5 µs = 200 kHz（MCR 第 10 位）
MR0 / MR1表里的值，开机 241比较值；241 > 240 永远比不上 = 0%
PWMC 第 0 / 1 位开始震时 1，停止时 01 = 这只脚由 PWM 控制；0 = 交给 EMR，EMR 设成“清零”= 一直低（MOS 关）

5. 毫秒级：震完以后的状态机

static void Ele_StatusTask(Ele_Handle_ts *pEle)          // 1303，主循环每圈：Ele_PollingTask() → 左、右各一次（960~963）
  ELE_PRESS_VIBRATING / ELE_RELEASE_VIBRATING:
    if((现在毫秒 − vibrateBeginTick) × 1000 > 导通时间 + 999)   // 1313 / 1322：按毫秒算，“向上取整再多 1 ms”
      → ELE_RELEASE_DEBOUNCE，记下 debounceBeginTick
  ELE_RELEASE_DEBOUNCE:
    if(现在毫秒 − debounceBeginTick > 8)                         // 1330：VIBRATE_DEBOUNCE_TIME_MS = 8
      → ELE_NO_VIBRATING
算一算：导通时间是多少，这一侧霍尔要“闭眼”多久

为什么要这一段“闭眼”：第 4 课讲过，Ele_IsVibrating()（894 行）只要状态不是 ELE_NO_VIBRATING 就返回 1，按键算法就跳过这个键。线圈电流只有半毫秒，但通电产生的磁场、按键被踢以后的机械晃动都会让霍尔读数乱跳一阵，消抖就是等它平静下来。另一个函数 Ele_IsTureVibrating()（926 行）只认“真正在震”的两个状态，不含消抖，给调试推送用。

6. 几条附加规则

6.1 同一时间只震一个线圈（SINGLE_COIL_AT_A_TIME = 1）

两个线圈共用一个 7 V 升压，同时震电流太大。所以左键要震时，如果右线圈正在“按下震 / 松开震”（不算消抖），就先不震，把请求存起来（990~996 行，gxCacheVibrate），等 5 ms 后由 Ele_OnlyOne()（1407 行）补震。

读代码时注意到：补震时调用的总是 Ele_…KeyReleaseProcess()（1416、1420 行），不管存起来的是按下还是松开；也就是说被推迟的“按下振感”会用释放振感的导通时间来补。而且只存得下一个请求，后来的会覆盖先来的。按下、释放导通时间设得一样时没区别。

6.2 动态导通时间（GUI“调试配置 → 动态导通时间”，默认关）

打开后，导通时间按按下时的段位打折（1263 行 Ele_CalculateDuration()）：实际 = 设定 × durationScale[段位] ÷ 1024，表在 209 行，近似 设定 × 100 ÷ (段位 × 2 + 100)。段位越深，震得越短。段位来自第 4 课的 Ele_UpadteSegment()（每 1 ms 存进 nowHallSegment[]）。

6.3 自动振动（GUI“调试配置 → 自动振动”）

打开后不用按键，每隔“振动触发周期”（最少 20 ms）自动调一次按下振动（1428~1453 行），用来连续测试手感。这两项调试参数只存在 RAM 里，重启恢复默认。
