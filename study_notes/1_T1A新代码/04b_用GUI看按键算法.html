2. GUI 上每个框是固件里的什么

GUI 上固件里注意
currentRawtemp[k]：翻转、滤波之后的值（my_misc.c:600~607 → wCurrentRaw）⚠ 名字叫 Raw，其实不是芯片原始读数。芯片读数 = 16383 − currentRaw（再加上滤波的影响）。按下时它变大
baselineBtmgwBottomBaseline[k]底部基线（按到底时的 temp）。只增不减
baselineTopgwTopBaseline[k]顶部基线（松开时的 temp）
crtSegmentnode[k]段位 0 ~ 100
maxSegmentxSegInfo.wMaxSegmentValue = 100（my_misc.c:606）⚠ 永远是 100（写死的常数，表示“段位最大值”），不是“这次按到的最深段位”
设置RT：生效 / 失效bmEnableMask = 0xF0 / 0x00；固件只看第 7 位（my_misc.c:105）失效时固件用默认 10 / 30 / 20，不用滑块的值
AP值ap_value[i] ← wSegmentActuationPoint单位是段位（0 ~ 100）。按下门槛 = max(最低点 + 按下RT，AP)（第 4 课第 5 节）
按下RTrt_press_value[i]段位
松开RTrt_release_value[i]段位
MouseInfo 里的 AP / RT 值EEPROM 里存的配置 xRtCfg（GetRT 读回）⚠ 选了“失效”时，这里显示的是存着的数，不是正在生效的 10 / 30 / 20
按键速度（次数/秒）不读固件：GUI 用 Windows 鼠标钩子（MouseHook.cs）数电脑收到的左键点击能检验“按下 / 松开”真的报给了电脑，适合测快速触发
设置按键：左键 / 右键包里的 key = VK_LBUTTON 0x01 / VK_RBUTTON 0x02固件内部 k = 1 是左键、k = 0 是右键，Hall_SyncParam() 会换过来（my_protocol_mouse.c:80）

3. 一个包长什么样

GUI 和固件用同一种包（my_protocol.h:34 PacketHeader_ts、PayloadHeader_ts）：

55帧头02收件人01发件人CK校验和LL长度低LH长度高TT类型CC命令SS子命令KK键数据…
  • 收件人 / 发件人：0x01 = 电脑（HOST），0x02 = 鼠标（MOUSE）。电脑发给鼠标是 02 01，鼠标回电脑是 01 02。
  • 长度 = 从“类型”开始到数据结束有几个字节，低字节在前。
  • 类型：0x02 = 请求（要回复），0x03 = 回复。命令：0x01 读信息、0x02 读配置、0x03 写配置。
  • 校验和 = 收件人 + 发件人 + 两个长度字节 + 后面所有字节，只留低 8 位（固件 my_protocol.c:41；GUI CommandClass.cs CalculateChecksum()，跳过帧头和校验和自己）。
  • 所有 16 位的数都是低字节在前（GUI 的 GetInfo(v1, v2) = v2 × 256 + v1）。
动手：拼一个“设置RT”包（GUI 松开滑块时调 SetRT()，CommandClass.cs）
动手：解读一个“读 RawData”回复包（GUI 点“开始读RawData”后每 100 ms 发一个请求，四种轮流：左 Raw → 右 Raw → 左 Segment → 右 Segment）
